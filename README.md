# 光景 Wallpaper · 260911

Rust + egui 原生桌面壁纸应用，提供简洁中文控制界面、美女 / 风景分类多选、上一张 / 下一张以及定时更换桌面背景，不展示壁纸列表。原图在更换时自动下载保存。

日期版本：`260911`（2026-09-11）；Cargo 版本为 `260911.0.0`。

## 运行

安装 Rust 后，在项目目录运行：

```sh
cargo run --release
```

手动打开显示主窗口；`cargo run --release -- --minimized` 最小化启动。
首次运行默认注册当前程序为登录自启动，之后自启携带 `--minimized` 参数。macOS 使用 LaunchAgent，Windows 使用登录启动项。可在左侧关闭自启。注册后不要移动或删除可执行文件；移动后需重新开关自启。

## 上一张 / 下一张

左侧「上一张壁纸」「下一张壁纸」直接更换桌面背景。上一张返回本次运行中成功设置过的壁纸；没有上一张时按钮禁用。下一张优先恢复向前的历史，历史末尾从当前分类获取新壁纸。手动切换与自动更换记录到同一历史中。历史只在本次运行中保留。

切换期间按钮暂时禁用；设置失败不推进历史。手动更换结束后自动轮换重新计时。

## 分类多选

点击分类按钮切换选中状态，可同时选择「风景」和「美女」，至少保留一个分类。两类同时选中时，每次获取新壁纸会等概率随机选择一个已选分类，并从该分类的随机结果中获取图片；可能连续选中同一分类。单分类仍按原有顺序获取。上一张 / 下一张仍优先导航已显示的历史；修改分类选择会清除向前历史，后续新壁纸来自所选分类。选择立即保存，旧版单分类配置自动兼容。

## 自动更换

左侧开启「定时更换当前分类」，选择 **1 分钟、5 分钟、10 分钟**，或选择「自定义时间」输入 **1–1440 分钟**。设置自动保存，重启后恢复。

首次更换在所选间隔后执行；修改时间、开关或切换分类会重新计时。后台线程独立于窗口绘制，最小化到 Dock / 任务栏后仍会轮换。关闭程序退出并停止轮换。电脑休眠期间不更换；恢复后不会补做所有错过的轮换。每轮操作结束后重新等待所选间隔，网络下载时间可能使实际间隔稍长。

自动轮换与手动下一张使用相同规则：多分类随机获取，单分类遍历后获取下一页。失败保留现有桌面，下个周期重试，错误会显示在状态栏。手动切换和自动轮换的原图均保存在系统图片目录的 `Wallpaper` 子目录，相同图片复用本地文件。

## 图片来源与网络

使用 [Wallhaven API](https://wallhaven.cc/help/api)，分类为 women / landscape，公开 SFW 图片无需 API Key。请求至少 3840×2160，并检查返回分辨率和下载文件尺寸，并完整解码验证图片。依赖本机网络能够访问 wallhaven.cc 及其图片域名；403、429 或断网会显示错误，可稍后点击下一张重试。图片版权归原作者。

## 应用图标与 macOS 打包

山景日光图标源文件为 `assets/icon.png`，macOS 图标为 `assets/icon.icns`。图标内嵌在程序中，直接运行也会应用到窗口 / Dock。

```sh
./scripts/package-macos.sh
# 优化构建：./scripts/package-macos.sh --release
```

双击生成的 `target/debug/Wallpaper.app` 启动。打包包含 Finder 图标和版本信息；将应用放在固定位置后再启用自启。发行版生成于 `target/release/Wallpaper.app`。

## DMG 安装包

```sh
./scripts/package-dmg.sh
```

脚本构建发行版、加入 Applications 拖拽安装快捷方式、临时签名并验证镜像。默认输出 `target/release/Wallpaper-260911-macOS-arm64.dmg`（文件名架构取决于构建机器），也可传入输出路径。本地构建未做 Apple 开发者签名和公证。

## 跳过用过的壁纸

获取新壁纸时，根据成功设置后的壁纸 ID 去重；记录保存在系统配置目录的 `WallpaperDesktop/used.json`，重启后仍生效。下载失败、设置失败和被取消的请求不会被记为用过。自动轮换始终寻找未使用的图片；手动上一张及返回后的下一张仍可导航历史。

每次尝试最多检查每个所选分类的 5 批结果，找不到新图时保留当前桌面并提示稍后重试。旧版本未记录实际使用情况，无法追溯，去重记录从此版本开始累计。
