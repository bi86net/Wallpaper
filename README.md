# 光景 Wallpaper

Rust + egui 原生桌面壁纸应用，提供简洁中文控制界面、美女 / 风景分类多选、上一张 / 下一张以及定时更换桌面背景，不展示壁纸列表。原图在更换时自动下载保存。

每次使用打包脚本发布时，自动按北京时间当天日期生成版本号，格式为 `YYMMDD`。例如 2026-09-19 显示 `260919`，Cargo 和应用包版本为 `260919.0.0`。版本在构建前确定一次，窗口、界面、应用包和默认 DMG 文件名保持一致；同一天多次发布使用同一日期版本。

## 运行

安装 Rust 后，在项目目录运行：

```sh
cargo run --release
```

手动打开显示主窗口；`cargo run --release -- --minimized` 最小化启动。
首次运行默认注册当前程序为登录自启动，之后自启携带 `--minimized` 参数。macOS 使用 LaunchAgent，Windows 使用登录启动项。可在左侧关闭自启。注册后不要移动或删除可执行文件；移动后需重新开关自启。

## 上一张 / 下一张

左侧「上一张壁纸」「下一张壁纸」直接更换桌面背景。上一张返回本次运行中成功设置过的壁纸；没有上一张时按钮禁用。下一张优先恢复向前的历史，历史末尾从当前分类获取新壁纸。手动切换与自动更换记录到同一历史中。历史只在本次运行中保留。

切换期间按钮暂时禁用；设置失败不推进历史。手动更换结束后自动轮换重新计时。

## 分类多选

点击分类按钮切换选中状态，可同时选择「风景」和「美女」，至少保留一个分类。两类同时选中时，每次获取新壁纸会等概率随机选择一个已选分类，并从该分类的随机结果中获取图片；可能连续选中同一分类。单分类仍按原有顺序获取。上一张 / 下一张仍优先导航已显示的历史；修改分类选择会清除向前历史，后续新壁纸来自所选分类。选择立即保存，旧版单分类配置自动兼容。

## 自动更换

左侧开启「定时更换当前分类」，选择 **1 分钟、5 分钟、10 分钟**，或选择「自定义时间」输入 **1–1440 分钟**。设置自动保存，重启后恢复。

首次更换在所选间隔后执行；修改时间、开关或切换分类会重新计时。后台线程独立于窗口绘制，最小化到 Dock / 任务栏后仍会轮换。关闭程序退出并停止轮换。电脑休眠期间不更换；恢复后不会补做所有错过的轮换。每轮操作结束后重新等待所选间隔，网络下载时间可能使实际间隔稍长。

自动轮换与手动下一张使用相同规则：多分类随机获取，单分类遍历后获取下一页。失败保留现有桌面，下个周期重试，错误会显示在状态栏。手动切换和自动轮换的原图均保存在系统图片目录的 `Wallpaper` 子目录，相同图片复用本地文件。

## 图片来源与网络

内置四种图片获取方式，无需 API Key：

- **Bing 图片搜索**：按「自然风景 2k 壁纸」「美女 2k 壁纸」搜索，启用严格安全搜索，提取搜索结果中的原图链接。优先加入候选列表，仍须下载后通过 2K 校验。
- **Wallhaven**：美女、风景，使用公开 SFW 接口。
- **Wikimedia Commons**：人物摄影、自然风景，过滤图片类型和尺寸；人物搜索排除裸露及绘画关键词，内容与专门的美女壁纸站有所不同。
- **Bing 每日壁纸**：仅用于风景分类，请求 UHD 原图。

各源并行查询，结果交错排列；发生 521、429、超时等错误的来源冷却 5 分钟，其余来源继续提供图片。单张下载失败会跳过并尝试后续图片。所有来源均在下载后验证实际尺寸至少 2560×1440（2K），并完整解码；不会放大低分辨率图片冒充 2K。多选随机及使用记录去重继续生效，新增来源使用带前缀的独立 ID，保留旧版 Wallhaven 使用记录。

Bing 搜图从公开搜索页面读取原图元数据，不使用缩略图。原图来自各结果站点；只下载公开 HTTPS 地址，验证域名解析和重定向，限制文件大小，按实际图片格式保存。搜索页面改版、验证页、原站防盗链或低分辨率图片会触发跳过或备用来源，不尝试绕过验证。Bing 搜图的去重 ID 使用规范化原图 URL 的 SHA-256，重启后沿用使用记录。

旧版 Bing Search API 已[退役](https://learn.microsoft.com/en-us/lifecycle/announcements/bing-search-api-retirement)，这里使用公开网页解析，因此可用性受页面结构变化影响。

图片版权归原作者。来源接口文档：[Wallhaven](https://wallhaven.cc/help/api)、[Commons API](https://commons.wikimedia.org/wiki/Commons:API/MediaWiki)。Bing 使用其主页每日壁纸接口，接口可用性取决于服务方与本机网络。

## 验证

```sh
cargo test
cargo clippy -- -D warnings
cargo build
```

当前开发环境为 macOS；Windows 支持由跨平台依赖提供，尚未在 Windows 实机验证。Linux 的自启和设置壁纸能力取决于桌面环境及系统字体。

## 应用图标与 macOS 打包

山景日光图标源文件为 `assets/icon.png`，macOS 图标为 `assets/icon.icns`。图标内嵌在程序中，直接运行也会应用到窗口 / Dock。

```sh
./scripts/package-macos.sh
# 优化构建：./scripts/package-macos.sh --release
```

双击生成的 `target/debug/Wallpaper.app` 启动。打包包含 Finder 图标和版本信息；将应用放在固定位置后再启用自启。发行版生成于 `target/release/Wallpaper.app`。

## DMG 安装包

```sh
./scripts/package-dmg.sh
```

脚本构建发行版、加入 Applications 拖拽安装快捷方式、临时签名并验证镜像。默认输出 `target/release/Wallpaper-YYMMDD-macOS-arm64.dmg`（文件名架构取决于构建机器），也可传入输出路径。本地构建未做 Apple 开发者签名和公证。

## 跳过用过的壁纸

获取新壁纸时，根据成功设置后的壁纸 ID 去重；记录保存在系统配置目录的 `WallpaperDesktop/used.json`，重启后仍生效。下载失败、设置失败和被取消的请求不会被记为用过。自动轮换始终寻找未使用的图片；手动上一张及返回后的下一张仍可导航历史。

每次尝试最多检查每个所选分类的 5 批结果，找不到新图时保留当前桌面并提示稍后重试。旧版本未记录实际使用情况，无法追溯，去重记录从此版本开始累计。

最低分辨率为 2560×1440；符合该尺寸的 2K、4K 及更高分辨率图片都可使用。原图无需缩放到 2K。
